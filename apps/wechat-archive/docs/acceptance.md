# 验收清单

## 自动化与真实账号必须分开

`tests/core.test.ts` 覆盖密码 / TOTP / AES-GCM、URL 与私网地址限制、路径 / CSV 安全、中文及 Markdown 转换、懒加载与缺图、原文身份提取和本地存储。

`tests/integration.test.ts` 使用隔离 PostgreSQL 和真实 API / 存储 / ZIP 实现，微信响应通过测试夹具注入。覆盖账号权限、CSRF、版本去重、图片独立修复、账号内任务互斥、暂停继续、清单合并、快照导出、下载权限回收、渠道失效、限流冷却，以及 10 个账号 / 1,000 条文章的检索和任务管理。S3 模式应运行同一套用例。

`tests/e2e/workspace.spec.ts` 通过 Chromium 完成初始化、TOTP、添加账号、文章检索、预览、标签、队列导出、下载和 390px 手机布局。验收样例明确标注为测试数据，不冒充真实抓取。

## 目标服务器上的上线检查

- [ ] 目标服务器 Linux / Docker 上，浏览器沙箱开启，受限代理有效；数据库 / Redis / 浏览器无公网端口。
- [ ] 实际域名 HTTPS、Cookie Secure、CSRF、未登录访问、角色隔离和 Cloudflare 缓存规则验证。
- [ ] 用真实 AppID / AppSecret 测试官方权限；记录出口 IP、账号主体、接口可用范围。
- [ ] 用真实管理员微信完成服务器扫码，确认 gh 原始 ID / AppID；错账号拒绝绑定；验证、选择账号、超时和会话失效流程可用。
- [ ] 核对最早、最新、群发、非群发、多图文次条；记录后台发表组数与展开后的文章数；不把发表次数当篇数。
- [ ] 清单核对报告列出：发现数、可获取数、正文成功数、失败文章、缺失图片、历史覆盖与两渠道差异。
- [ ] 中文、标题、引用、代码、表格、链接、懒加载图片与特殊排版抽样比对；未知作者 / 发布时间保持空值。
- [ ] 重复同步不重复，内容修改新增版本，源文章删除保留旧存档，最近 30 天与历史全量复查符合预期。
- [ ] 在官方分页、正文、图片和 ZIP 阶段停止 Worker / 浏览器，恢复后任务续跑且不产生重复版本。浏览器中断会重新枚举清单。
- [ ] 微信频控遵守 Retry-After / 至少 30 分钟冷却；一次恢复仍失败转人工处理，不循环刷登录。
- [ ] 本地目录和实际 R2 桶分别完成导入、预览、ZIP；未授权图片 / ZIP 不能访问。
- [ ] ZIP 离线打开，图片相对路径有效，CSV / manifest 元数据和失败状态准确；同名长中文文件名安全。
- [ ] 完成至少一次异机备份恢复：搜索、历史版本、图片及重新导出均正常。

没有真实账号权限和目标服务器时，上述项目保持待验收，不能由本地模拟结果勾选通过。微信后台适配器若不匹配实际页面，需要根据合法登录后的页面结构调整并补充回归测试。
