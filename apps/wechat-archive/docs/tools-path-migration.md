## 实施内容

汇总页源码和工具清单位于 `apps/tools-hub/`，发布目录为 `/var/www/junbao.ai/tools-hub/current`，由现有 Caddy 直接提供静态文件。主站自动同步只处理 `site/`。

文藏使用 `APP_BASE_PATH=/wechat-article-archive`，构建和运行配置一致；`APP_ORIGIN=https://tools.junbao.ai`。业务 API 内部路径没有变化，公开接口、静态资源、图片和下载统一放入工具路径。没有数据库结构变更。历史预览图片在返回时转换地址；导出包仍使用相对路径。

登录、初始化与工作区提供「所有工具」。会话 Cookie 限定在工具路径，登录时清理原根路径 Cookie；已有登录会话可能需要重新登录。账号和密钥不会重建。
